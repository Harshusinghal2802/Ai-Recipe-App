# 🍽️ Recipe App

A modern MERN Stack Recipe Application where users can explore, create, and save their favorite recipes.

## ✨ Features

* 🔐 User Authentication (Register & Login)
* 🍳 Create your own recipes
* 📖 Browse recipes created by other users
* ❤️ Add or remove recipes from Favorites
* 👨‍🍳 View all recipes created by you in **My Recipes**
* 👤 User Profile section
* 📱 Responsive UI for Desktop & Mobile
* ⚡ Fast and easy-to-use interface

---

## 🛠️ Tech Stack

### Frontend

* React.js
* React Router
* Axios
* CSS / Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* bcrypt

---

## 📂 Main Sections

### 🏠 Home

Browse all available recipes shared by users.

### ❤️ Favorites

Save your favorite recipes and access them anytime.

### 🍳 My Recipes

Manage all recipes created by your account.

### 👤 Profile

View your profile information.

---

## 🚀 How It Works

1. Register or log in to your account.
2. Explore recipes created by the community.
3. Create and publish your own recipes.
4. Add any recipe to your Favorites.
5. Manage your own recipes from **My Recipes**.
6. View your account details from the **Profile** page.

---

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/recipe-app.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:5173
```
